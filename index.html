Lagres automatisk på denne enheten.

Slik setter du opp (én gang)

  1. Gå til developer.spotify.com/dashboard og trykk Create app.
  2. Lim inn Redirect URI-en over under Redirect URIs (nøyaktig lik, inkludert evt. avsluttende /), og huk av for Web API og Web Playback SDK.
  3. Kopier Client ID fra appens innstillinger og lim den inn her. (Client Secret trengs ikke.)
  4. Mens appen er i «Development mode»: legg til e-posten til Spotify-kontoen som skal brukes under User Management.
  5. Kontoen må ha Spotify Premium. På PC/Mac (Chrome, Edge, Firefox, Safari) kan musikken spilles rett i nettleseren.
  6. iPad / mobil: nettleseren kan ikke spille selv – appen blir da en fjernkontroll. Åpne Spotify-appen (på iPaden eller en PC/høyttaler i hallen), start en sang og sett på pause, trykk Oppdater og velg enheten under «Avspillingsenhet».

Kampklar

«Gjør klar til kamp» lagrer sangene på denne enheten, så musikken virker selv om nettet i hallen faller ut. «Foreslå dropp» analyserer lyden og setter starttid for sangene i valgt kategori som står på 0:00.

Publiser fast liste for alle

Listen som publiseres er alle Plex-sangene i Mål, Timeout og Pause med dropp, samt auto-stopp og volum. Last opp fila til GitHub-repoet (Add file → Upload files) – etter 1–2 minutter får alle på kampdj.no den nye listen.

Dropp-finner

Går gjennom sangene i kategorien som ikke har manuelt satt dropp (også de med automatisk forslag), én og én. Trykk D når droppet kommer – tiden lagres (minus reaksjonstiden) og neste sang starter. ←/→ hopper 5 sek, Shift+←/→ 1 sek. Sanger med manuelt dropp hoppes over.

Legg til enkeltsang

Tips: Spill av sangen med «Test dropp», og trykk «Nå» når droppet kommer for å hente eksakt posisjon.

    Brukervilkår og personvern

    Les gjennom og godta for å bruke KampDJ. Du kan lese dem igjen når som helst nederst på siden.

    Versjon

    1. Om tjenesten

    KampDJ er en nettbasert app for avspilling av kampmusikk (mål, timeout og pause) på idrettsarrangementer. Tjenesten tilbys av gratis og «som den er».

    2. Bruk av tjenesten

    KampDJ skal brukes til avspilling av musikk på arrangementer i regi av klubben eller laget. Du skal ikke forsøke å omgå tilgangskontroll, belaste tjenestene appen kobler seg til unødig, eller bruke appen til å spre musikk eller innloggingsdata videre til andre.

    3. Musikk og rettigheter

    KampDJ leverer ikke musikk selv. Den som bruker appen og arrangøren er selv ansvarlige for at musikken er lovlig anskaffet, og for at nødvendige lisenser for offentlig fremføring er på plass (for eksempel fra TONO og Gramo).

    4. Tjenester fra andre

    Appen kan kobles til Spotify og Plex. Da gjelder også deres vilkår. Spotify krever blant annet Premium for avspilling. KampDJ er ikke laget, støttet eller godkjent av Spotify eller Plex.

    5. Lydnivå og sikkerhet

    Den som styrer musikken har ansvar for et forsvarlig lydnivå, særlig når barn og unge er til stede.

    6. Ansvar

    Vi gjør vårt beste for at appen fungerer, men gir ingen garanti for drift eller tilgjengelighet. er ikke ansvarlig for tap eller ulemper som følge av feil, avbrudd eller bruk av appen, så langt loven tillater det.

    7. Endringer

    Vilkårene kan endres. Ved vesentlige endringer blir du bedt om å godta dem på nytt.

    2. Kort fortalt

    KampDJ har ingen egen server og ingen brukerkontoer hos oss. Vi samler ikke inn personopplysninger, og vi bruker ikke sporing, analyse eller reklame.

    3. Hva som lagres på enheten din

    Appen lagrer følgende lokalt i nettleseren på enheten du bruker (localStorage og nettleserens lagringsplass for filer). Det sendes ikke til oss:

    • sanglister, starttider, innstillinger og hvilke sanger som er spilt i runden
    • innloggingsnøkler for Spotify eller Plex, hvis du kobler til dem
    • lydfiler som lagres med «Gjør klar til kamp»
    • tidspunktet du godtok vilkårene

    4. Tjenester appen bruker

    • GitHub Pages leverer nettsiden. GitHub mottar IP-adressen din og tekniske opplysninger når siden lastes.
    • Google Fonts leverer skrifttypene. Google mottar IP-adressen din når skriftene lastes.
    • Plex (plex.tv og klubbens Plex-server) brukes for å hente og spille musikken når Plex er valgt som lydkilde.
    • Spotify brukes bare hvis du logger inn med Spotify. Da gjelder Spotifys personvernerklæring.

    5. Grunnlag og lagringstid

    Opplysningene på enheten er nødvendige for at appen skal fungere slik du ber om (personvernforordningen artikkel 6 nr. 1 bokstav b og f). De ligger der til du sletter dem, for eksempel med knappen nedenfor eller ved å tømme nettleserdata.

    6. Barn

    KampDJ er laget for voksne ledere og funksjonærer. Appen behandler ikke opplysninger om spillere eller utøvere.
