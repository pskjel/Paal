Lagres automatisk på denne enheten.

Slik setter du opp (én gang)

  1. Gå til developer.spotify.com/dashboard og trykk Create app.
  2. Lim inn Redirect URI-en over under Redirect URIs (nøyaktig lik, inkludert evt. avsluttende /), og huk av for Web API og Web Playback SDK.
  3. Kopier Client ID fra appens innstillinger og lim den inn her. (Client Secret trengs ikke.)
  4. Mens appen er i «Development mode»: legg til e-posten til Spotify-kontoen som skal brukes under User Management.
  5. Kontoen må ha Spotify Premium. Bruk en nettleser på PC/Mac (Chrome, Edge, Firefox eller Safari) – mobilnettlesere støttes ikke av Spotify sin nettleserspiller.
